1. 數值微分：對測試函數 f(x) = sin(x) 在 x0 = 1.0 處估計其一階導數。
   實作並比較「前向差分」、「後向差分」及「中央差分」在步長 h 從 1.0 漸進遞減到 1e-14 過程中的絕對誤差變化，
   觀察在浮點數中，截斷誤差與捨入誤差互相平衡後得到的的最佳步長（Best step）與數值不穩定現象。
   延伸題要求推導並實作 二階中央差分公式 以觀察其更劇烈的捨入誤差，並利用Richardson 外推法在較大步長下獲取高精度（O(h^4)）估計。

2. 數值積分：對測試函數 g(x) = e^(-x^2) 在區間 [0, 1] 上進行定積分。

   當子區間數 n 從 2 漸進加倍至 1024 時，計算與高精度參考解的絕對誤差，並藉由誤差比值驗證各方法的理論收斂階數。

3. 自適應求積（Adaptive Quadrature）- 延伸題 Q2-1：
   實作自適應辛普森法，探討函數 h(x) = sin(1/x) 在區間 [0.5, 1.5] 上的定積分。
   透過誤差控制與遞迴細分，記錄其自適應切分點與子區間寬度。
   觀察其在面對含有快速震盪與平緩變化的區間時，是否能將計算節點自動且智慧地集中在快速震盪的劇烈處。

4. 高斯求積（Gaussian Quadrature）- 延伸題 Q2-2：
   實作二點高斯求積算法（節點取自 2 階勒讓德多項式的根 1/sqrt(3)），
   對 3 次多項式 m(x) = 5x^3 + 3x^2 + 7x - 18 在區間 [1, 10] 上進行積分。
   驗證其是否如理論所述，僅使用 2 個函數評估點，即可對 3 次多項式達到零理論誤差的精確積分，並與需要大量節點的等距複合方法進行效率與精度上的對比。

三、實作：（說明在C++程式實現上，是否遇到什麼困難，是如何解決。所設計的程式，是否有什麼地方比較特別，說明之）

1. 遇到困難 自適應辛普森遞迴崩潰 (Exit Code 139)：
   在實作自適應辛普森 (adaptiveSimpson)的時候，因為將上一層大區間的積分估計值 S 原封不動地當成參數傳入子區間（沒有隨著 L 與 R 各自更新為其對應的半區間積分值），且子區間的中點位移寫錯，導致隨區間縮小，誤差 L + R - S 永遠無法收斂至 15*eps 以下。這引發了無限遞迴。
   解決方法：重新釐清算法機制，左半 [a, mid] 應傳入已算出之左區間近似 L，右半 [mid, b] 傳入 R，並修正中點為 (a+mid)/2 與 (mid+b)/2

2. 特別之處 計算優化：
   本程式在 gaussianQuadrature 中，將 std::sqrt(3) 之倒數預先定義為 inv_sqrt3 = 0.5773502691896257645 常數，避免了迴圈與呼叫中昂貴的平方根與除法運算。

1. 數值微分測試結果與最佳步長：
   - Forward 差分：誤差在 h = 1e-8 達到最小，約 5e-9 階。
   - Backward 差分：誤差在 h = 1e-8 達到最小，約 5e-9 階。
   - Central 差分：誤差在 h = 1e-5 達到最小，約 1e-12 階。
   分析：實驗得出的中央差分最佳步長（1e-5）與理論 best step = (ε_mach)^(1/3) = (2.22e-16)^(1/3) = 10^(-5.2) 相符。小於此 h 之後，雖然截斷誤差變小，但因為浮點數相減與分母除以 2h，導致捨入誤差急遽膨脹，證明了總誤差並非單調遞減。
   - 二階中央差分：由於分母為 h^2，誤差在 h 較小時更早爆發，在 1e-3 左右達到最佳，更小則快速退化。
   - Richardson 外推：在較大的 h = 1e-3 時即獲得極高的精度（1e-12 階，相當於中央差分在最優步長 1e-5 下的極限），這是不需要微小 h 即可達成O(h^4)的體現。

2. 數值積分與收斂階數驗證 (n=2~n=1024)：
   - n 增加一倍時，各算法 error[n]/error[2n] 的 ratio 收斂表現：
    梯形法則：比值穩定收斂在 4.0 左右（驗證了 O(h^2) 理論階數）。
    中點法則：比值穩定收斂在 4.0 左右（驗證了 O(h^2) 理論階數，且同 n 下誤差約為梯形之半）。
    辛普森法則：比值穩定收斂在 16.0 左右（驗證了 O(h^4) 的高階收斂速率）。
